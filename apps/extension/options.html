Vitrinka recorder

Settings

The recorder talks only to the vitrinka instance you set here. The token is a vkp_ personal access token (or the instance write token); project ↔ domain mapping lives in each vitrinka project's settings. If the vitrinka CLI is set up on this machine these are filled in for you — you only need this page to override them.

Recorder data

Captured events and screenshots are held on disk until vitrinka has them — an outage never discards a recording. Data belonging to a session vitrinka has already finished is cleared automatically; a live recording is never touched.
